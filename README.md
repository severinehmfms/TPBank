# Titre : TP Bank
## Sujet : Conception du noyau d’une banque en ligne

## Auteur : Séverine Hori Maitrehut

## Description : 
Application en java, en mode console, dans un premier temps pour les tests
Base MySql
L'exercice repose principalement sur la partie conception, puis le développement du code java

###Installation :
-Installation préalable de mysql.
-Script sql/TPBank.sql à importer dans la base de données
-Les informations de connection à la base de données MySql doivent être notées dans le fichier database/DatabaseConnection
